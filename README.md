# superagent-lead：让 TRAE 当大管家

一个给 TRAE 用的技能（Skill）。装上以后，遇到步骤多、能拆开分头做的任务，TRAE 会当“大管家”：先拆任务，给每一块写一张交接单，派给几个执行者分头做，交回来以后逐块验收，最后汇总。

大管家只管拆、派、验，自己不动手干具体的活；每个执行者是一个新开的 TRAE 对话，只拿一张交接单，只改单子上写明的文件，做完交回大管家。

## 它怎么干活

1. **先判断要不要拆。** 一个文件、十几分钟能做完的事，直接做，不拆。
2. **写任务总表。** 在项目里建 `.superagent/进度.md`：目标、不能做的事、每一块任务和状态。进度表只有大管家改。
3. **每块写一张交接单。** 六项缺一项就不派：目标、输入、能改什么、不能做什么、交回什么、怎么验收。两块任务不能改同一个文件。
4. **派出去。** 没有依赖的几块，各开一个新的 TRAE 对话，每个对话只贴一张交接单；有依赖的，等上游验收通过再派。
5. **逐块验收、汇总。** 执行者说“做完了”不算，大管家自己按验收标准跑命令、看文件。过了记下证据；不过就打回原来那个对话改。全部通过后，大管家一个人合到一起，再整体验一遍。

付款、删除、对外发送、改权限，任何执行者都不能自己做，必须停下来问你。

| | 大管家（1 个） | 执行者（每块 1 个） |
|-|-|-|
| 看得到 | 全局目标、进度表、所有人的产出 | 只有自己那张交接单和它列出的输入 |
| 负责 | 拆、派、验、汇总 | 把自己那一块做完，交回产出和证据 |
| 跟谁说话 | 你，和每个执行者 | 只跟大管家交接，不直接找你 |
| 能改什么 | 只改进度表 | 只改交接单里写明的文件 |

## 安装

把 `superagent-lead` 这个文件夹放进 TRAE 的技能目录：

- 只在某个项目里用：复制到项目的 `.trae/skills/superagent-lead/`
- 所有项目都能用：复制到全局技能目录，TRAE 国内版是用户目录下的 `.trae-cn/skills/`，国际版是 `.trae/skills/`

```bash
git clone https://github.com/aduoge/superagent-lead.git
mkdir -p 你的项目/.trae/skills
cp -r superagent-lead/superagent-lead 你的项目/.trae/skills/
```

不用 git 的话，在网页上点 Code → Download ZIP，解压后把 `superagent-lead` 文件夹复制过去。打开 TRAE 设置 → 规则和技能，能看到它就装好了。

## 使用

在 TRAE 里说“用总管模式帮我做……”，后面接你的大任务。建议加一句“先给我看任务总表和交接单，我同意后再派”。

```text
用总管模式帮我做：给我的项目加一个“每周复盘”功能，一块查现有的数据怎么存，一块写新功能，一块写测试。
先给我看任务总表和交接单，我同意后再派。
```
